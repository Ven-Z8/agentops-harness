AgentOpsOperator Console

The working UI for governed AI coding runs.

A run is a governed attempt to resolve a real GitHub issue on a real repo. It produces a patch plus an evidence bundle. Every claim on screen traces to evidence — and a failed run is a first-class outcome, never hidden or spun.

01 · home · live Runs list Live + stored runs, KPIs, honest status chips, per-run risk badges. 02 · the heart · live with ?id= Run detail Stage timeline, test exits, evidence citations, the patch, event replay. Without an id it shows the curated dmr case study. Includes showcase mode. 03 · compose · live gate New governed run Pick a real issue, choose a worker, prove the bug exists at base before dispatch — the gate runs the real negative contract. Dispatch hands off to the governed CLI. 04 · library · case study Task-spec library Pinned commits, FAIL_TO_PASS / PASS_TO_PASS lists, environment identity — curated content, not yet served from storage.
